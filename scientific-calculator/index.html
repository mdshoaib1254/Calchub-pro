Frequently Asked Questions

By default, trigonometry functions (sin, cos, tan) evaluate in Degrees (DEG). You can toggle to Radians (RAD) using the button directly above the keypad.

The 'log' button calculates the common logarithm using base 10: log(100) = 2. The 'ln' button calculates the natural logarithm using base e (Euler's number ~ 2.71828): ln(e) = 1.

For squares and cubes, click the x² or x³ buttons. For arbitrary powers (such as 2 raised to the 10th power), enter 2, press xʸ, type 10, and press equals.
